# Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

O formato é baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/),
e este projeto segue o [Versionamento Semântico](https://semver.org/lang/pt-BR/).

## [1.0.0] - 2024-XX-XX

### Adicionado
- Versão inicial do aplicativo
- Interface visual para criação de layouts Elementor
- Suporte a seções com layouts full-width e boxed
- Sistema de colunas (100%, 50/50%, 33/33/33%, 25/75%, 75/25%, 33/66%, 66/33%)
- Widgets disponíveis:
  - Heading (Títulos H1-H6)
  - Text Editor (Texto rico)
  - Button (Botões com link e tamanhos)
  - Image (Imagens com alt text)
- Edição de propriedades em tempo real
- Reordenação de elementos
- Exclusão de elementos
- Exportação JSON compatível com Elementor
- Importação de arquivos JSON
- Preview JSON em tempo real
- Modo de visualização (preview)
- Suporte multiplataforma:
  - Windows (instalador e portátil)
  - Linux (AppImage)
  - macOS (DMG e ZIP)

### Recursos Técnicos
- Electron 42.2.0
- React 18.2.0
- TypeScript 5.2.2
- Tailwind CSS 3.4.1
- Vite 5.1.0
